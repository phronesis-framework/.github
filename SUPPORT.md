# Support

## Where to ask

| Question type | Channel |
|---|---|
| Bug report | GitHub issue in the affected repo (use the bug-report form) |
| Feature request | GitHub issue (use the feature-request form) or Discussions |
| Usage question | GitHub Discussions in the affected repo |
| Security report | See [SECURITY.md](SECURITY.md) — **not** a public issue |
| Conduct concern | See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |
| Conventions, CI, or org-level question | Issue in `phronesis-framework/.github` |

## Before opening an issue

1. Search existing issues and discussions.
2. Check [`docs/conventions/`](docs/conventions/) — many "support" questions are conventions in disguise.
3. Reproduce on the latest released version where possible.

## Response expectations

This is a volunteer-maintained project. We aim for:

- Acknowledgement of new issues within one week.
- A first substantive response within two weeks.
- Security reports — see [SECURITY.md](SECURITY.md).

Outside those targets, a polite ping on the issue thread is fine.
